## 三、为什么会亏这么多：四条根因

### 1. 「突破」是噪声突破（最根本）

Q 的 4 笔信号，突破前 50 根新高的幅度只有 **+2.4% / +6.8% / +2.5% / +6.6%**，而当时的
ATR% 是 **2.7%~3.5%** —— **突破幅度不到 2 倍 ATR**，本质上就是「贴着前高的一根放量长上影」，
不是有效突破。

对照：同一套参数在 AGT/AKE/BANK 上的 9 笔盈利交易，突破幅度为
**+7.4% / +8.8% / +9.8% / +13.3% / +14.3% / +15.1% / +24.4% / +26.7% / +31.5%**。
「突破幅度」把 Q 的亏损笔与其它品种的盈利笔完全分层。

### 2. 进场时暴涨已经走完（追在喷发末端）

RSI14 **80~89**、距 MA20 **+15%~22%**、6 根脉冲 **+17%~26%** —— 买入点就在脉冲的最高潮。
之后 2~22 根内回落，**MFE 几乎为 0**（进场后从未有效浮盈）。

### 3. 12% 固定止损在高波动里被跳空穿透

Q 是 ATR% 3% 级别的品种，单根 K 线常出现 8%~15% 的振幅。止损是「判定 → 下一根开盘平仓」，
暴跌根之后的开盘价可能已经跌了 25%（#4），于是 **12% 的止损变成 −25% 的实际亏损**。

### 4. 满额名义价值把单次错误放大成账户级灾难

脚本 `qty = notional / close`，而 `notional = 1000` = 账户全部本金（1x 名义、无杠杆放大）。
四笔连续亏损按复利叠加：1 000 → 846 → 726 → 606 → 351，**−64.9%**。
若名义为 200（账户 20%），同样这四笔按复利只亏约 **−12%**（单笔最大 −5.1%）。

## 四、v2（AgtPumpPro）改了什么

| 改动 | v1 | v2 | 依据 |
|---|---|---|---|
| 突破幅度 | 无要求 | **≥ 7%**（`brkMin`，0=关） | 直接过滤 Q 的 3 笔噪声突破 |
| 单笔名义 | 1 000（100% 本金） | **200（20%）** | 单笔最大亏损从账户 12%~25% 降到 2.4% |
| **止损执行** | 信号后**下一根开盘**平仓（瀑布会跳空穿透） | **盘中止损**：脚本 `plot("STOP")` → 引擎按止损价成交 | Q #4 实际成交从 −36.8% 收敛到 **+8.8%** |
| **移动止损** | 浮盈 20% 才激活、回撤 15% | **浮盈 8% 激活、回撤 6%** | +10% 的浮盈即可把止损抬到 +3.4%，不再「从哪来回到哪去」 |
| **保本** | 无 | **浮盈 6% → 止损抬到成本** | 极端瀑布下最差保本 |
| 分批止盈 | 无 | 提供但默认关 | 打开后 AGT 同一批信号 +228% → +59%，得不偿失 |
| 趋势破位 | 无 | 浮亏且收盘跌破 EMA200 → 退出 | 提前脱离下跌段 |
| 时间止损 | 120 根 | 120 根 | 保持 |

### 瀑布专项：Q #4 那笔 −36.8% 是怎么被救回来的

用户回放截图（2026-09-26 20:00 入场，09-27 01:00 出场）显示：**入场后一度浮盈约 +10%，
随后一根 1 分钟瀑布直接砸穿 12% 止损，最终成交 −36.8%**。两个原因：

1. **止损从来没被激活**：`保本` 关闭、`吊灯` 要等浮盈 +20% 才激活 —— +10% 时两者都没动，
   止损还停在 −12% 的入场价下方。
2. **止损只能下一根开盘成交**：PineTS 账本只产出「开/平仓」，引擎对 Pine 信号只有
   `forceClose`（下一根开盘平仓）→ 瀑布那根的开盘价已经是 −25%，止损=形同虚设。

修复（平台级 + 策略级）：

- **平台级**：给 Pine 信号加「盘中止损通道」——脚本用 `plot(stopPx, title="STOP")` 输出止损位，
  适配器把它接到信号的 `obStopLoss`，引擎在持仓期间**只收紧地**维护 `sub.stopLoss`。
  引擎的止损判定本来就是盘中的（`p <= stopLevel` 时按止损价成交），于是瀑布被止损价挡住。
- **策略级**：`保本 6%` + `吊灯 8% 激活 / 6% 回撤`。

效果（同一笔 #4）：**入场价 0.035853，峰值浮盈 ≈ +10% → 离场 +8.8%**（止损抬到 +3.4%，
瀑布还没砸到止损位就已经在盘中止盈离场）。

### 离场档位（同一批信号，只改离场，1000 名义）

| 档位 | 保本 | 吊灯激活/回撤 | Q | AGT | AKE | BANK | 最差单笔 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 收益优先（仅盘中止损） | 关 | 20% / 15% | −12.1% | **+188.5%** | +162.6% | −12.1% | −12.1% |
| **平衡（默认）** | **6%** | **20% / 15%** | **+8.8%** | +101.9% | **+174.6%** | −0.1% | **−4.5%** |
| 控回撤 | 6% | 8% / 6% | +8.8% | +115.0% | +85.8% | +2.3% | −12.1% |

- **保本只「保护」不「截断」**：+6% 抬到成本，瀑布最多回到 0；吊灯仍是 20%/15%，让 AGT/AKE 的大波段跑完
- **收紧吊灯（8%/6%）并不是免费的**：AGT +101.9% → +115.0% 略升，但 AKE +174.6% → +85.8% 直接腰斩，整体更差
- **分批止盈会截断趋势**：+12% 平一半后 AGT 只剩 +48.7%、AKE +50.2%，所以默认关闭
- 没有一档能在所有品种上同时最优 —— 这是收益与回撤的固有权衡，按目标选档

## 五、使用建议

1. **名义价值 ≤ 账户 20%**：这是本次亏损的第一放大器。1000 本金 → 单笔 200，四笔连亏也只有 −13.7%。
2. **新品种（上市 < 30 天）不要用本策略**：Q 的第一笔信号在第 5.2 天，正是流动性最差、振幅最大的阶段。
3. **`brkMin` 不要低于 5%**：低于 2×ATR 的「新高」在这类币上等于噪声。
4. **保本 6% 只保护不截断，可以常开；分批止盈会截断趋势，默认关掉**（需要先落袋再开）。
5. **Q 这类「上市初期暴涨暴跌」的品种，适用 v2 小仓位模式**；追求收益优先用 AGT/AKE 这类有持续趋势的标的。
6. 若单笔连续亏损 ≥ 3 笔，暂停该品种，等 ATR% 回落到中位数附近再启用。

## 六、还没解决的（诚实边界）

- Q 在 10 月确实暴涨 +193%，v2 只抓到 1 笔（+8.8%）——**「先挖坑再主升」这类形态，突破追多只吃到一小段**，主升浪的主体仍拿不到。下一步考虑「回踩确认入场」（本轮测试过：Q 变成 4 胜 5 负 / −6.0%，但 AGT 也从 +228% 降到 +8%，属于另一种取舍，暂不作为默认）。
- `brkMin = 7%` 是在 4 个品种、16 笔样本上得到的阈值，换品种前应先小仓位跑一段验证。
- **跳空风险没有消失**：盘中止损是按「止损价」成交，但若某根 K 线直接跳空到止损价下方（开盘即低于止损位），成交价仍会是更差的跳空价 —— 只能靠小仓位兜底。
- 收紧移动止损会牺牲一部分趋势收益（AGT +37.7% → +23.0%），这是「保住浮盈」与「吃完波段」的固有取舍。
