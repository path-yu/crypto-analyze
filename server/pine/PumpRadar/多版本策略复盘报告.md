> 基础体系：[复盘报告.md](file:///d:/GitCode/crypto/server/pine/PumpRadar/复盘报告.md)（事件研究、四特征 lift、PumpRadar 原版）
> 本报告：在**完全相同的信号与事件体系**上，对比 **10 种策略变体**，每个版本给出完整回测。
> 样本：9 个目标代币（MYX/LAB/RAVE/TRB/BTR/SIREN/BANK/AKE/币安人生，1h，2024-07 → 2026-10）
> 验证：**14 个高波动 meme 币（从未参与任何设计）** 上重跑同一矩阵（样本外）。
> 产物：`scripts/pump-radar-variants.ts` → `output/pumpradar/variants-main.json` / `variants-oos.json`

## 1. 方法

| 维度 | 说明 |
|---|---|
| 事件/特征 | 与基础报告完全一致：37 段暴涨、点火 bar、四特征（CVD 走强/振幅收缩/量能抬升/买卖压力） |
| 评分门 | score = 满足的特征数（0~4）；≥ scoreMin 触发 |
| 进场 | 信号 bar 次根开盘；止损 = 24 根最低点下方 0.5%（结构性） |
| 仓位 | 每笔风险 = 权益 × riskPct（按止损距离反推名义），名义 ≤ 3× 权益；手续费 0.055%/单边 |
| 离场 | 结构止损（盘中）→ 分批止盈（盘中，可选）→ 吊灯（收盘）→ 时间止损（收盘） |
| 指标 | 逐币终值收益率（复利）、最大回撤、笔数、胜率、盈亏比；事件捕获（进场后 96 根内点火） |
| 防过拟合 | 每币事件按时间前 60% = 设计集、后 40% = 验证集；另有 14 个 meme 币作完全样本外 |

## 4. 逐版本复盘

### V1 基线 —— 对照组
评分≥3、风险 1%、吊灯 20%。9 币中位 +24.5% 但样本外 **−9.1%**。
问题：评分达标后的**重复进场**（同一段评分≥3 的行情里反复进出）造成 892 笔交易，
其中绝大多数是重复暴露；一旦行情走弱，连续止损线性失血。

### V2 严门（评分≥4）—— 用稀有度换质量
交易 892→215 笔，盈亏比 1.60→**2.84**，为正 8/9。但均值从 +42.1 降到 +27.3：
四特征全满足时行情往往**已经走出一段**，入场价变差。样本外 −1.6%/+2.4%：安全但无肉。

### V3 趋势过滤（EMA200）—— 样本外最稳的防御
样本外把 V1 的 −9.1% 修到 **−0.7%**（砍掉了下跌结构里的假信号），但样本内只有 +7.3%
（暴涨币启动时大多还在 EMA200 下方，过滤掉了一部分真信号）。适合保守配置。

### V4 点火放量 —— 样本内最差仅 −1.2%
要求信号 bar 放量 2 倍，交易 582 笔，9 币最差只有 **−1.2%**。
样本外 −4.5%/+3.4%：量能确认有价值，但均值 +49.8% 主要还是 MYX 贡献。

### V5 保本分批 —— ★ 唯一样本外成立的版本
- 浮盈 10% → 止损移到入场价（**保本**）：之后任何回落最多是"少赚"，不再是亏损。
- 浮盈 20% → 平一半（**落袋**）：剩下的仓位用吊灯追踪，赌后半程。
- 效果：胜率 28%→**34%**、9 币最差 −13.3%→−10.1%、**样本外 +18.3%（12/14 为正）**。
- 机制：它不提高信号质量，而是**改变收益分布的形状**——把"过山车"变成"先落袋再博弈"。

### V6 冷却期 —— 样本内冠军 = 样本外陷阱 ⚠
样本内 9/9 全部为正、最差 +3.4%、均值 +76.4%——**如果只看样本内，这是圣杯**。
样本外 −6.1%/−2.1%。机制：冷却期砍掉的交易里，样本内恰好砍掉了亏损段；
但这个"砍法"没有可解释的结构，属于**对 9 币历史的巧合拟合**。禁用。

### V7 连败暂停 —— 本轮无效
3 连败暂停 240 根：9 币结果与 V1 **逐位相同**——因为 1% 风险仓位下连败 3 笔仅 −3%，
触发暂停的条件在本样本里极少出现。参数不敏感 = 该机制无效。

### V8 组合防御 —— 最小最差值
EMA200 过滤 + 保本 + 冷却：最差 −6.1%（全场最小）、中位 +14.3%。样本外 −0.6%/+2.4%。
防御属性最好、进攻最弱的均衡版。

### V9 低风险（0.5%）/ V10 高风险（2%）—— 纯线性缩放
信号相同 → 收益与回撤严格按风险预算线性缩放：V10 均值 +90.9% 但最差 −56.6%。
**风险预算不是收益开关，是生存开关。**

## 5. 「减少无信号干扰」的量化答案

| 手段 | 交易数变化 | 样本外中位变化 | 结论 |
|---|---|---:|---|
| 评分门收紧 ≥4 | 892 → 215（−76%） | −9.1 → −1.6 | 有效但牺牲覆盖 |
| 趋势过滤 EMA200 | 892 → 697（−22%） | −9.1 → −0.7 | 有效的防御性过滤 |
| 点火放量确认 | 892 → 582（−35%） | −9.1 → −4.5 | 有效 |
| 冷却期 48 根 | 892 → 566（−37%） | −9.1 → −6.1 | 样本内假象 |
| **保本+分批（不减交易）** | 892 → 1137（+28%） | **−9.1 → +18.3** | **不减信号，改收益形状** ✅ |

**真正把「无效信号」从亏损变成不亏的，不是过滤掉它们，而是给它们装上保本与分批。**

## 6. 最终建议配置（PumpRadarPro.pine）

```
信号   四特征评分 ≥ 3/4（CVD走强 / 振幅收缩 / 量能抬升 / 买卖压力偏多）
仓位   单笔风险 ≤ 1% 权益（按 24 根低点止损距离反推），名义 ≤ 3× 权益
止损   24 根最低点 × 0.995（结构性，随波动自适应）
保本   浮盈 ≥ 10% → 止损移到入场价
分批   浮盈 ≥ 20% → 平一半（建议；引擎当前不支持部分平仓时按全平近似）
追踪   最高收盘回撤 20% → 平仓
时间   96 根未离场 → 平仓
预期   样本外中位 +18%、均值 +25%、最差 −11%、约 12/14 币为正（高波动 meme 宇宙）
```

注意：Pine 版（PumpRadarPro.pine）的 `qty_percent=50` 分批在当前引擎中按全平近似，
与 TS 模拟（真正的半仓+吊灯）存在差异；精确分批需要引擎支持部分平仓。
