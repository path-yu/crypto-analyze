## 1. 怎么定义「暴涨区间」

对每个币做滚动扫描：**任意 72 根（3 天）窗口内，自区间最低 low 起涨幅 ≥ 50%** 即标记一段暴涨，并做非极大抑制 + 区间重叠去重（同一段行情常被相邻窗口重复识别）。

6 个币去重后共 **94 段**。示例（AKE，一年内 951 倍）：

| 低点 | 低点价 | 高点 | 高点价 | 涨幅 | 历时 |
|---|---|---:|---|---:|---:|---:|
| 2026-04-09 01:00 | 0.000220 | 2026-04-11 11:00 | 0.000670 | **+204%** | 58 根 |
| 2026-02-23 01:00 | 0.000253 | 2026-02-24 22:00 | 0.000497 | +96% | 45 根 |
| 2026-03-07 06:00 | 0.000218 | 2026-03-07 08:00 | 0.000385 | +76% | **2 根** |

注意最后一行：**有些暴涨两根 K 线就走完**（+76%），这类只能靠"提前埋伏"或"第一根就追"，不存在从容的进出场。

## 2. 特征对照（暴涨确认 bar vs 全样本基线）

「确认 bar」= 自区间低点起涨 15% 的那一根收盘（一个可以真实下单的时刻）。

| 特征 | 暴涨 bar 中位 | 基线中位 | 倍数/差值 |
|---|---:|---:|---:|
| **成交量 / 96 均量** | **2.25** | 0.63 | **3.6×** ← 最强 |
| 成交量 / 24 均量 | 2.03 | 0.74 | 2.7× |
| 布林带宽 % | 17.7% | 8.6% | 2.1× |
| ATR% | 5.27% | 2.51% | 2.1× |
| 带宽 / 240 中位 | 1.55 | 0.97 | 1.6× |
| 振幅 / 240 均值 | 1.10 | 0.89 | 1.2× |
| 距 MA20 | +6.1% | -0.3% | 符号翻转 |
| 距 MA50 | +3.5% | -0.6% | 符号翻转 |
| 连阳根数 | 2 | 0 | — |
| 近 6 根涨幅 | +8.1% | -0.2% | 符号翻转 |
| RSI14 | 57.5 | 48.4 | +9 |
| **相对 50 根新高** | **-10.4%** | -6.7% | **几乎无差别** ← 反直觉 |

**为什么新高突破没用**：暴涨币启动时处在"跌了很久、刚被买起来"的位置，上方还有大量套牢盘没收复，所以启动那一刻离 50 根新高还很远。用「新高」当条件是"用错的特征"——实测它捕获 79/94（看着不错），但产生 **999 段误报，精度只有 7%**。

## 3. 候选入场规则的捕获能力

判定口径：规则在「暴涨区间内、见顶之前」触发算捕获；误报按**连续触发段**计一次（否则同一段行情会重复计数几十次）。

| 规则 | 捕获率 | 误报段 | 精度 | 距顶剩余根数 | 入场时已涨 | 入场后还能涨 |
|---|---:|---:|---:|---:|---:|---:|
| 距MA20>10% 且 量>3 | 69/94 | 140 | **33%** | 22.3 | +44.5% | +61.5% |
| 破50新高 且 量>2 且 24h涨>15% | 67/94 | 149 | 31% | 23.7 | +48.8% | +60.2% |
| 量>6 且 6根涨幅>6% | 55/94 | 126 | 30% | 23.6 | +44.1% | +63.0% |
| 振幅扩张>1.5 且 6根涨>8% | 59/94 | 149 | 28% | 27.9 | +62.7% | +58.9% |
| 量>5 且 6根涨幅>5% | 62/94 | 179 | 26% | 24.6 | +44.1% | +62.2% |
| 量>10 | 42/94 | 127 | 25% | 21.5 | +48.0% | +60.7% |
| 破50新高 且 量>5 | 51/94 | 159 | 24% | 24.3 | +47.1% | +63.4% |
| 量>3 且 6根涨幅>3% | 77/94 | 434 | 15% | 27.6 | +38.6% | +68.1% |
| 破50根新高（单条件） | 79/94 | 999 | 7% | 30.1 | +43.7% | +66.7% |

**两条关键读数**：
1. **确认入场时价格已经涨了 38%~66%** —— 追涨的代价很明确：半程已经没了。
2. **入场后平均还能再涨 58%~68%，且距见顶还有 22~28 根** —— 所以**离场设计决定了最终能不能赚钱**。

## 4. 策略设计

### 4.1 入场（PumpHunter.pine）

```
放量    成交量 ≥ volMult × SMA(成交量, 96)          // 默认 5 倍
脉冲    单根涨幅 ≥ bar1Pct%（默认 12%）              // 也可改用近6根累计涨幅
结构    收盘 > MA20 且高出 ≥ distMaPct%（默认 2%）
可选    要求突破 50 根新高（默认关；复盘显示它没用）
```

### 4.2 离场（针对「尽量不被打止损 + 在高处了结」）

| 机制 | 说明 |
|---|---|
| 初始止损 | **固定百分比**（默认 12%）。**不要用 ATR**：暴涨当下 ATR% 会被撑到 20%~50%，`3×ATR` 等于 -100% 的"假止损"，实测会让 BANK/LAB/MYX 亏到 -80% 以上 |
| 吊灯移动止损 | `止损 = max(止损, 持仓期最高价 × (1 − trailPct%))`，默认 **10%**；可设「浮盈满 N% 才激活」 |
| 可选保本 | 浮盈达 bePct% 后把止损抬到成本价（默认关） |
| 时间止损 | 持仓 96 根仍未赚钱 → 视为假信号，退出后再等下一次放量 |

### 4.3 两个**实现上的坑**（写 Pine 时必踩）

1. **状态变量必须用 `var`**。Pine 里顶层 `float x = 0.0` 是**每根 bar 重新初始化**的；写成不带 `var` 时编译器会把它当逐 bar 标量放在 `step()` 内部，
   于是每根都从 0 开始 → 永远走「新成交初始化」分支 → **止损一次都不会触发、仓位被拿到回测结束**。
   实测症状：6 个币各只成交 1 笔、改任何止损参数结果都完全一样。改成 `var float stopPx = 0.0` 后立刻恢复正常（AKE 从 1 笔变 23 笔）。
2. **离场判定必须用「上一根收盘就已确定的止损」，绝不能用本根的 high 设止损、再用本根的 low 去触发它**。
   同一根内 high/low 的先后顺序未知，这样写会凭空造出「刚进场就被打掉」的假信号（实测 9 笔里 4 笔持仓仅 1 根就离场）。

## 5. 参数选择（样本内 6 币 → 样本外 14 币）

用「逐币权益收益率%」的 **中位数 / 均值 / 最差** 三个口径评估，而不是盈亏金额之和——AKE 一年 951 倍，金额之和会被单个彩票单完全带偏。

**入场参数（离场固定 12% 止损 + 12% 移动）**

| 入场 | 样本内中位/均值/最差 | 样本外中位/均值/最差 |
|---|---|---|
| 量5 单根12% | -67 / +8 / -72 | **-6 / -2 / -25** |
| 量3 单根12% | -37 / +27 / -72 | -12 / -4 / -25 |
| 量5 6根10% | +92 / +111 / -53 | -15 / -8 / -74 |
| 量5 6根6% | +125 / +117 / -35 | -43 / -27 / -64 |
| 量3 6根0% | -67 / +101 / -71 | -67 / -55 / -74 |

> 注：上表固定用 12% 移动止损来「先挑入场」。换成下面选定的 10% 移动止损后，
> 最优入场（量5/单根12%）的样本内中位由 **-67%** 变为 **+20%** —— 这也说明入场与离场必须一起看。

**离场参数（入场固定 量5/单根12%）**

| 离场 | 样本内中位 | 样本外中位 | 样本外均值 |
|---|---:|---:|---:|
| 止损12% 移动**10%** 立即激活 | **+20** | **0** | **+4** |
| 止损12% 移动15% 立即激活 | -16 | -4 | -0 |
| 止损12% 移动25% 立即激活 | -63 | -12 | -5 |
| 止损12% 移动10% 激活@25% | -61 | -6 | -2 |
| 止损8/18% 移动10% 立即激活 | +20 | 0 | +4（与 12% 相同：10% 移动先触发，初始止损几乎不生效）|

→ 取 **量5 / 单根12% / 6根0% / 12% 初始止损 / 10% 吊灯移动止损 / 立即激活 / 时间止损 96 根**。

## 7. 真正可迁移的经验

1. **追涨的入场规则只能"抓到"，不能"预测"**；它的价值取决于**离场**，因为确认后仍有 60%~68% 的空间和 22~28 根的时间。
2. **移动止损的宽度是最大的单一杠杆**：同一批入场，25% 吊灯 vs 10% 吊灯，样本外中位差 **+12 个百分点**（-12% → 0%）。
   暴涨币的一根 K 线就能回撤 20%+，宽止损等于把 60%~90% 的浮盈全数还回去。
3. **止损用固定百分比，不要用 ATR**：波动率正是在你要进场的那一刻爆掉的，`N×ATR` 会退化成"没有止损"。
4. **别用「突破 N 根新高」筛选暴涨**：这类币启动时上方全是套牢盘，新高条件只会引入大量误报（精度 7%）。
5. **`var` 是 Pine 状态的生命线**（见 §4.3），这也是本次唯一一处"看起来策略失效、其实是脚本写错"的地方。
6. 这套规则更适合**当作"已有仓位的加仓/离场模板"**，而不是独立的开仓系统：
   把它当成「已有底仓 + 放量突破时用 10% 吊灯跟随」的减仓纪律，比当独立策略更合理。

## 9. 第二轮：埋伏型入场（PumpAmbush）

追涨型的问题是"触发时行情已走完 40%~66%"。第二轮换思路：**不追启动，改在启动之前的收缩期提前布仓**。
产物：[PumpAmbush.pine](file:///d:/code/Bunm/crypto-analyze/server/pine/PumpAmbush/PumpAmbush.pine)、[scan-ambush.ts](file:///d:/code/Bunm/crypto-analyze/scripts/scan-ambush.ts)

### 9.1 先做纯统计预检验（不写策略）

统计口径：20 个币 · 1h · 165k 根统计 bar · **178 段**暴涨。预测窗 K=72 根（3 天）。

- **信号** = 某根 bar 处于"启动前夜"状态
- **命中** = 该根之后 K 根内出现暴涨区间的**最低点**（启动点）
- **精度** = 命中 / 信号段数；**基线** = 随机一根 bar 在 K 根内撞上启动点的概率（= **5.72%**）
- **lift** = 精度 / 基线；**覆盖** = 有多少暴涨段在启动前 K 根内出现过该信号

| 信号 | 信号段 | 精度 | **lift** | 覆盖暴涨段 |
|---|---:|---:|---:|---:|
| S1 量枯竭 volR<0.5 | 18589 | 5.1% | **0.90** | 172/178 |
| S2 波动压缩 atrPct<0.7×240均 | 1855 | 5.4% | **0.95** | 88/178 |
| **S3 窄幅 48 根振幅<35%** | **371** | **21.3%** | **3.72** | **157/178** |
| S3a 窄幅<20% | 922 | 4.8% | 0.83 | 110/178 |
| S3b 窄幅<25% | 630 | 8.7% | 1.53 | 132/178 |
| S3b + 收在区间下40%（买低位） | 6207 | 3.8% | 0.66 | 114/178 |
| S3b + 收在区间上40% | 5859 | 3.6% | 0.63 | 103/178 |
| S3b + 缩量（volR<1） | 17253 | 3.2% | 0.55 | 126/178 |
| S3b + 站上 MA200 | 3177 | 4.0% | 0.70 | 87/178 |
| S3b + 均线粘合（MA20/MA200 差<5%） | 1095 | 4.3% | 0.75 | 89/178 |
| E 首根放量 volR≥2 且 量>1.5×前根 | 8008 | 7.0% | 1.22 | 165/178 |
| S3b + 首根放量 | 6893 | 4.2% | 0.73 | 114/178 |

### 9.2 三个反直觉结论

1. **「量枯竭」与「波动压缩」不但无效，还弱于随机**（lift 0.90 / 0.95）。
   原因：非暴涨的垃圾币**同样**长期缩量横盘——这两个特征在对照组里比比皆是，没有区分度。
2. **仅「48 根振幅收敛到 35% 以内」有效**：lift 3.72、覆盖 88% 的暴涨段、且信号只有 **371 段**（20 币一年），足够稀有、可操作。
3. **给这个信号加任何附加过滤，lift 全部掉回 1 以下**（低位/高位/缩量/均线粘合/首根放量无一例外）。
   连"收紧到 <20% 或 <25%"都更差 —— 极致窄幅更多是"下跌途中的死水"，而非启动前夜。

### 9.3 埋伏型策略与回测

```
入场  48 根振幅 < 35%（可选：只在区间下 X% 处布仓）
      每段横盘只布一次（条件消失才重新武装，避免反复进出）
离场  初始止损 8%~15%（或放在 48 根区间下沿下方 1%）
      + 吊灯移动止损 10%~15%
      + 时间止损 72 根（没启动就走）
```

| 只在区间下 50% / 固定止损 15% / 移动 15% | **+19%** | **-21%** | -9% | -33% |

### 9.4 结论

1. **埋伏型也没有稳定优势**：样本外中位 -4.6%（最好一行 -1%）、均值 +4%~+8%，和追涨型的 +3.6% 同量级。
2. **在设计集（6 币）上最优的那一行，样本外是 -21%** —— 这本身就说明没有可复制的结构；
   而"样本外最好"的那一行又是挑样本外挑出来的，不能当作干净的超额收益。
3. **埋伏型唯一的真实优点：样本量好得多**（7 笔/币 vs 1.5 笔/币），结果不再被单笔彩票主导。
   若要把这条路线继续做下去，应该以它为基础扩币种池。
4. **最关键的认知：lift ≠ 盈利。**
   窄幅信号的 lift 有 3.72，但**精度只有 21%** —— 剩下 79% 的布仓要各自付一次 8%~15% 的止损，
   而命中那 21% 里也未必都能吃到大涨（吊灯止损 10%~15% 会切掉一部分）。
   算一遍就知道：`0.21 × (+40%) − 0.79 × (+12%) ≈ -1%`，**期望值天然就在 0 附近**。
   **所以纯统计指标（精度/lift）只能用来筛"值不值得写策略"，不能用来判断策略能不能赚钱 —— 必须落到赔率与止损上一起算。**
5. 两条路线合起来的可复用结论：**"启动前"和"启动时"都无法可靠预测暴涨的幅度，
   能挣钱的只有赔率结构（窄幅 → 小止损）**；而在这个样本上，连赔率结构也被 79% 的失败率吃平了。

## 10. 第三轮：主升浪（MainWave）—— 与「暴涨脉冲」是两回事

用户要求"结合追涨脚本，抓真正的主升浪"。先明确一件事：**主升浪 ≠ 暴涨脉冲**。

| | 暴涨脉冲（第一轮） | 主升浪（本轮） |
|---|---|---|
| 定义 | 72 根（3 天）内自低点涨 ≥50% | zigzag(25%) 上涨波段且**历时 ≥240 根（10 天）** |
| 样本 | 94~178 段，涨幅 50%~200% | 20 币 **57 波**，涨幅 +31%~+320%，历时 **250~1800 根** |
| 最强启动特征 | 成交量倍数（3.6×） | **破 100 根新高（lift 102）** + 成交量倍数（5.3×） |
| 方向特征 | 「破 N 根新高」**几乎没用**（lift 0.87~1.26） | **均线多头排列 / MA50 上行在启动 bar 上中位=1、基线=0** |

所以"新高突破"没区分度；而主升浪本身就是"不断创出新高"的持续趋势，所以突破新高是最强特征。

### 10.3 结论：为什么这一版反而最差

1. **入场根本不"稀有"**：本想说"主升浪只有两三波、其余时间不做"，
   但"破 100 根新高 + 放量"这套条件在 22 个币上一年触发了 **494 次**（≈22 笔/币）——
   远超"两三波"。真相是：**100 根突破的一年触发次数（2403 段/20 币 ≈ 120 段/币）远多于主升浪数量（3 波/币）**，
   其中只有 **3.5%** 真正启动主升浪。
2. **95%+ 的假信号 × 每笔 8%~12% 止损 = 结构性失血**：固定 1000 名义仓位下，
   每次假突破亏掉账户的 ~10%，20 多次就是 -60%~-70%，几波真主升浪的盈利补不回来。
3. **lift 102 是"相对优势"，不是"绝对可用"**：精度 3.5% 意味着 96.5% 的信号是无效的。
   用户要的"过滤掉无效信号"，靠 OHLCV 特征做不到 —— 特征已经把相对区分度推到很高了（lift 100），
   但绝对精度依然只有个位数百分比。
4. **"≥50% 收益"这个目标在当前方法下不成立**（见 §10.4）。

### 10.4 关于「其他品种也要 50% 以上收益」

三个集合的一致结果是：**追涨 中位 0.0%、埋伏 -4.6%、主升浪 -19.4%~-67%**，全部无法达到 50%。
这不是调参问题，而是**方法的天花板**：

- 这些收益来自"抓到 2~3 波主升浪中的至少 1 波"，而**单波涨幅（+31%~+320%）确实足以带来 50%+ 的账户收益**——
  所以目标本身是可达的，**瓶颈在"如何做到只做那 2~3 次、而不被 20 多次假信号拖死"**。
- 要把精度从 3.5% 提到 50%+ 需要 ~15 倍的提升，OHLCV 的价量特征做不到；
  真正能大幅提升精度的是行情之外的信息：**新合约上线 / 板块轮动 / 交易所公告 / 链上资金流**。
- 在只有价量数据的前提下，更现实的路线是：**扩到几百个币的池子 + 用选币把池子缩到几十个 + 每笔风险压到 1~2%**，
  靠"极少数赢单"覆盖"大量极小的止损"；但这也只是把期望值从负拉到 0 附近，不是稳定盈利。

### 10.5 唯一可以直接拿去用的东西：主升浪清单

57 波主升浪在启动确认时**长这样**（可以直接当人工盯盘的 checklist）：

1. **成交量 ≥ 96 根均量的 3.7 倍**（这是最强单一特征，5.3 倍于基线）
2. **收盘突破前 100 根最高价**（主升浪就是不断新高）
3. **均线多头排列：MA20 > MA50 > MA200**（启动确认 bar 上几乎全部满足）
4. **MA50 正在上行**（10 根比较）
5. 收盘 **高出 MA200 约 11%**、近 24 根涨幅约 +12%
6. 布林带宽 **≈12%**（基线 6%）、48 根振幅 ≈17%

**反过来用它做风控**：如果这 6 条里有 3 条以上不满足，大概率不是主升浪，不要做。

### 10.6 最有价值的一个发现：**「只做最稀有的那几波」是唯一单调有效的改进**

用户"主升浪只有两三波、其余时间能不做就不做"的直觉**被数据证实了**。把突破窗口从 4 天拉到 60 天，
真·验证集（随机 22 币，从未参与调参）的表现**单调改善**：

| 突破窗口 | 新22 中位 | 新22 均值 | 新22 最差 | 新22 笔数（≈几笔/币） |
|---:|---:|---:|---:|---:|
| 100 根（4 天） | **-56%** | -19% | -103% | 169（7.7 笔/币） |
| 240 根（10 天） | -28% | -17% | -102% | 129（5.9 笔/币） |
| 480 根（20 天） | **0%** | +4% | -79% | 89（4.0 笔/币） |
| 720 根（30 天） | **+1%** | **+7%** | -104% | **66（3.0 笔/币）** |
| 960 根（40 天） | 0% | +6~9% | -81% | 54（2.5 笔/币） |
| 1440 根（60 天） | 0% | +4~6% | -81% | 42（1.9 笔/币） |

**读法**：
- 入场稀有度是**唯一的单调杠杆**：从 4 天到 20 天，中位改善 **+56 个百分点**，笔数从 7.7 笔/币降到 4 笔/币。
  这正是"少做"的价值 —— 每次假信号的成本是固定的（8%~12%），减少次数就是线性减少失血。
- 但**它在 20 天之后收敛**：再稀有也只是把中位钉在 0%、均值 +4~9%。
  也就是说，**稀有化能把策略从"亏"拉到"打平"，但拉不到盈利**。
- 60 天窗口下只有 **1.9 笔/币**，已经完全符合"只做两三波"。可它依然只有 +4~6% 均值。
- 最差币仍是 -81%~-104%：**固定 1000 名义仓位 + 1000 本金 = 单笔满仓**，
  一次 25% 的移动止损就是账户 -25%，连续几次就能打穿。这是仓位管理问题，不是信号问题。

**因此最终的诚实结论**：把入场稀到极致（60 天突破 + 放量 + MA200 上方）能让策略"不亏"，
但**价格/成交量数据本身不包含"哪一波会成功"的信息**。要跨品种做到 50%+，
缺少的不是更好的指标，而是**价量之外的信息**（上新、板块、公告、链上资金）。

## 11. 第四轮：选币（Selection）—— 从 745 个合约里筛出"值得做"的池子

用户要求"执行选币步骤"：不再试图改进入场信号，而是**换一个维度**——
同样一套 MainWave 入场，只把它跑在**被筛出来的池子**上，看表现能否显著优于"随机全宇宙"。

产物：[select-coins.ts](file:///d:/code/Bunm/crypto-analyze/scripts/select-coins.ts)，数据 `output/select/`。

### 11.1 三步流程

| 步骤 | 做什么 |
|---|---|
| `list` | 取 binanceusdm 全部 **745** 个 USDT 永续 |
| `stage1` | 逐个拉 **1d 一年**数据，算：日均成交额、上市时长、25% zigzag 波段数/涨幅、MA200 上方占比、趋势效率比、年化波动 → `metrics.json` |
| `stage2` | 硬门槛（历史 ≥180 天、日均额 ≥30 万 U）+ **百分位排名**打分 → top40 池子 + 随机对半 A/B 留出 |
| `eval` | 用 MainWave **脚本默认参数**（不做任何再调参）在六个集合上跑，对比 |

### 11.2 踩到的数据质量坑（必须记录）

第一版选池的 top1/top2 是 **RAVE（波段 +8048%）、ENSO（30 日区间 +108500%）** —— 明显是**数据假象**。
查原始缓存：**ENSO 上市首日的日线是 `low 0.001 → high 3.579`**，一天的插针就伪造出 35 万倍区间。
`maxWave` / `maxRunup30` 这类**极大值型指标**被这一根 K 线彻底污染，而 z-score 又被少数极值把均值/方差带偏，
结果"选币"变成了"选数据异常币"。

**两处修正**（对任何"用历史极值选币"的工作都适用）：
1. **跳过上市前 30 根日线**再算指标（`WARM_DAYS=30`），把上新插针排除；
2. **打分改用百分位排名**（0~1）而非 z-score —— 百分位对极值天然免疫。

同时**改掉打分哲学**：不追"历史涨得最猛"（那类多是低流动性 meme，在 1h 上制造大量假突破），
而偏"**可持续的平滑趋势**"：

```
score = 0.30×P(MA200 上方占比) + 0.30×P(趋势效率比) + 0.20×P(min(波段数,4)) + 0.20×P(波段涨幅中位数)
（P = 在同门槛集合内的百分位排名；效率比 = |期末−期初| / Σ|逐日变动|，1=单边趋势，≈0=来回震荡）
```

修正后的 top40 变成了可解释的名单：JST / TAKE / ZAMA / VVV / MUBARAK / PTB / SOON / ZEC / NEAR / PLUME /
COTI / EUL / AGT / CHR / RECALL / SOLV / APR / EIGEN / ALICE / GRASS / KAITO / BLESS / … / HYPE / APE / …

### 11.4 结论（诚实版）

1. **选币确实提供了一点正向信息，但很弱**：选池 A+B（中位 +7.0% / 均值 +26.6% / 58% 为正）
   全面优于同门槛随机对照（-0.6% / +2.5% / 47.5%），三项指标各改善 **+7.6pt / +24pt / +10pt**。
   留出半区 B 单独看最亮（中位 +11.7%、65% 为正），但**半区 A 中位 -0.7%**，两者相差 12pt ——
   **说明这个优势在 n=20~40 的样本量下仍处于噪声量级**（均值差 t≈1.5，达不到显著）。
2. **打分不是单调有效的**：居中的 40 个（中位 -23.9%）反而**比垫底 40 个（-1.5%）更差**。
   原因是"垫底组"里混了大量**低波动 TradFi 合约**（AAPL/TSLA/NVDA/SPY/XAU/COPPER…），它们来回在 0 附近，
   天然不亏多少；而"居中带"是真正混沌的加密币。这说明**打分只能划出一个"顶部"，
   往下的名次没有可靠的区分度**。
3. **门槛本身几乎没用**：只按"历史 ≥180 天 + 日均额 ≥30 万 U"筛，随机对照中位 -0.6%，
   与随机全宇宙的 +0.7% 基本一致 —— **流动性/上市时长过滤不带来 alpha**，收益全部来自顶部打分那一小段。
4. **"每个品种都 ≥50%"依然不成立**：即便在最好的选池里，也只有 **23/40 为正（58%）**、最差 **-70%**，
   而且收益被少数大赢单撑起（ZEC +217、VVV +197、SAGA +162、NEAR +147、FOLKS +135、EUL +116、JST +98…），
   **中位（典型币）只有 +7.0%**。这跟第 10 轮"价量数据无法预测哪一波会成功"的结论完全一致：
   选币能把期望值往正方向推一点点，但**推不到稳定 50%**。

### 11.6 杠杆叠加测试：选池 × 入场稀有化（结论：**不能叠加**）

§11 里"选池"是正的（+7.0% vs -0.6%），§10.6 里"入场稀有化"也是正的（突破窗口 20 天→60 天单调改善）。
自然要问：**这两个杠杆能不能相乘？** 在池A 上挑窗口、池B 留出确认：

| 突破窗口 | 池A 中位 / 均值 / 为正 | 池B（留出）中位 / 均值 / 为正 | 同门槛随机 中位 / 均值 / 为正 |
|---|---:|---:|---:|
| 720 根（30 天，默认） | -0.7 / +22.7 / 10-20 | **+11.7 / +30.5 / 13-20** | -0.6 / +2.5 / 19-40 |
| 960 根（40 天） | -10.5 / +10.9 / 9-20 | +9.8 / +23.0 / 13-20 | -1.8 / +2.6 / 18-40 |
| 1440 根（60 天） | -13.5 / +15.8 / 9-20 | +9.4 / +17.0 / 11-20 | **+5.4 / +9.8 / 21-40** |

**读法**：
1. **对"已经选过的池子"，稀有化不加分、反而减分**：池B 中位 11.7% → 9.8% → 9.4%，
   池A 由 -0.7% 掉到 -13.5%。也就是说**稀有化这一杠杆只在"没选过"的宇宙里有效**。
2. **随机对照的表现恰好相反**：随机对照随窗口拉长而改善（-0.6% → +5.4%），
   这正是 §10.6 观察到的现象。
3. **两个杠杆抓到的是同一个东西**：都是"避开那些在 1h 上反复制造假突破的币"。
   选池从"选币"这一端做，稀有化从"减少交易次数"这一端做，**做完一个，另一个就没有边际收益了**。
4. **叠加后的最佳格子仍远达不到 50%**：全表最好的一格是"选池 + 30 天窗口"（池B 中位 +11.7%），
   与"不选池 + 60 天窗口"（随机对照中位 +5.4%）在同一量级。**没有相乘效应**。

**因此第四轮的最终结论**：选币是一条**很弱的单边改进**（+7.6pt 中位），
且它**与"少做"互相替代而非互补**；两条杠杆加起来也推不到"每个品种 50%+"。
这再次指向同一个结论：**在只有价量数据的前提下，50% 目标不可达**。
