## 0. 先说三件必须知道的事

1. **拿不到"一年"的数据**：BTW 合约 2026-06-04 才上市，全历史只有 **3241 根 1h（135 天）**。本报告分析的是**全部可用历史**，不是一年。

3. **结论是"有边缘但很窄、样本很小"**：
   - 追空（跌破、阴线、24h 大跌）在 BTW 上**全部负期望**，样本 269 笔的 `24h 跌 ≤ -15%` 每笔 −5.62%（k=12）。

## 4. 最终策略：BTW_Blowoff（做空）

### 4.1 规则

**入场（全部满足才出信号，引擎在下一根开盘做空）**
1. **`RSI(14) ≥ 85`** —— 唯一有效的核心门槛
2. （可选，默认关）窗口 24 根涨幅 ≥ X%
3. （可选，默认关）滞涨确认 `收盘 < 前收` / 破位确认 `收盘 < EMA20`

**离场**
- **吊灯移动止损**：`止损 = min(入场价 × 1.20, 入场后最低价 × 1.12)`，只下移；浮盈 ≥15% 后激活
- 通过 `plot(title="STOP")` 交给引擎做**盘中止损**（插针按止损价成交）
- **时间止损**：持仓 168 根仍浮亏 → 平仓（浮盈时不打断，实测很少触发）

**仓位 / 杠杆**：`qty = 100 / 收盘价`（10% 权益敞口）· **建议杠杆 ≤1x**

## 6. 风险与使用须知（务必读）

1. **样本极小**：合约只有 135 天，策略只成交 **9 笔**。置信度很低，不要按收益率线性外推。
2. **逆势交易**：这是逆着一条 166 倍的抛物线做空。加速段会连续触发信号 → 连续亏损（8/19 一天两笔 −20%）。
3. **止损不保证成交价**：引擎的 STOP 通道能覆盖盘中止损，但跳空开盘仍会滑价；单根 +54% 意味着理论上存在超出止损上限的成交。
4. **必须低杠杆 + 小名义**：建议杠杆 ≤1x、名义 ≤10% 权益（本报告口径）。
5. **别把它当趋势策略**：它只在"垂直拉升 + RSI 极值"时出手；一个月可能一次都不触发（2026-07 整月、2026-06 前半月都没有信号）。
6. **不覆盖"下跌趋势"**：2026-06-20~06-29 的 −73.77% 那种持续下跌段，本策略只有零星信号能参与（因为入场要求 RSI 极端超买）。
7. **资金费率未计**：热门新币做空时资金费率通常为正（多头付空头），对策略是顺风；但逼空阶段可能剧烈波动，实盘需单独核算。
